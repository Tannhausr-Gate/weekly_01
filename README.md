# Weekly Assigment #1: Manifest Validation


## Installation
1. **Clone the Repo**
```bash
git clone https://github.com/Tannhausr-Gate/SkillStorm_Weekly_01.git
cd SkillStorm_Weekly_01
```
2. **Install UV**
```bash
Windows: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
Mac: curl -LsSf https://astral.sh/uv/install.sh | sh
```

3. **Setup**: 
```bash
uv sync
```

4. **Running Tests**
```bash
uv run pytest
```
